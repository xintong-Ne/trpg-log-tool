# 跑团 Log 合并工具

这是一个本地 Streamlit 小工具：上传多个 txt log 文件，或直接粘贴 log 内容，按文件/来源选择底色、按人物名选择文字颜色，然后生成按时间排序的 docx。默认是白底黑字。

## macOS

双击 `start.command`。

如果系统提示没有权限，打开终端进入这个文件夹，运行：

```bash
chmod +x start.command
```

然后再双击。

## Windows

双击 `start.bat`。

## 使用方式

1. 选择“上传 txt 文件”或“粘贴记录”。
2. 按需要勾选输出选项。
3. 为每个文件/来源选择底色。
4. 为每个人物设置显示名、文字颜色，或选择删除该人物全部发言。
5. 如果启用了文件分段小标题，为每个文件/来源填写小标题；留空会插入一个白色空行。
6. 点击“生成 docx”。
7. 点击“下载 docx”。

## 支持的记录格式

工具会从每条记录开头识别“人物名 + 时间”。

支持带日期的格式：

```text
一块电子脑(3645066195) 2025-01-09 00:17:30
正文
```

也支持只有时间的格式，工具会把它当作同一天的记录来排序：

```text
爸你怎么被开了（2） 11:49:54
正文
```

人物名里可以有空格或状态信息：

```text
七海佑纪 SAN90 HP10/10 DEX70 11:50:03
正文
```

也支持日期时间在前、人物名在后的格式：

```text
2025-09-29 21:44:02 莱拉·奥拉里(758794368)
正文
```

也支持时间在前、尖括号人物名、内容同一行的格式：

```text
21:03:04 <misago> 电话随即被挂断。
```

如果人物名末尾有 `(123)` 或 `（123）`，会被识别为 QQ 号；没有也没关系。

## 输出选项

- 去除 QQ 号：每条记录开头不显示括号里的 QQ 号。
- 去除时间：每条记录开头不显示日期和时间。
- 去除括号开头内容：整条内容以 `（` 或 `(` 开头的记录不会输出。
- 去除 `[图片]`：整条内容只有 `[图片]` 的记录不会输出。
- 按文件分段加小标题：排序后每次切换来源时插入小标题；标题留空就是一个白色空行。
- 括号内容小一号 + 斜体：内容以 `（` 或 `(` 开头的整条记录会变小并变成斜体，包括前面的人物名。
- 括号内容单独染色：内容以 `（` 或 `(` 开头的整条记录会使用单独选择的括号颜色，包括前面的人物名。

第一次启动会自动创建 `.venv` 并安装依赖，所以会慢一些；之后启动会快很多。
