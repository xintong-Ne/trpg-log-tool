跑团 Log 合并工具启动说明
给完全不熟悉电脑操作的人看的版本


一、这个工具是什么？

这个工具可以帮你把多个跑团 txt log 合并成一个 Word 文档。

你不用写代码。
你只需要：

1. 安装 Python。
2. 打开这个工具文件夹。
3. 双击启动文件。
4. 在网页里上传 txt。
5. 选颜色。
6. 下载生成好的 docx。


二、先确认你拿到的文件夹里有什么

这个工具文件夹里应该至少有这些文件：

app.py
requirements.txt
start.command
start.bat
README.md

如果你是 macOS，用 start.command。
如果你是 Windows，用 start.bat。


三、安装 Python

Python 可以理解成“让这个工具能运行的底座”。
如果电脑里没有 Python，这个工具就跑不起来。


【Windows 安装 Python】

1. 打开这个网页：
   https://www.python.org/downloads/

2. 点击黄色或蓝色的下载按钮，下载 Python。

3. 打开下载好的安装包。

4. 安装窗口最下面通常会有一个选项：
   Add Python to PATH

   一定要勾选它。
   一定要勾选它。
   一定要勾选它。

   这个很重要。

5. 然后点击 Install Now。

6. 等它安装完成。


【macOS 安装 Python】

1. 打开这个网页：
   https://www.python.org/downloads/

2. 下载 macOS 版本的 Python。

3. 打开下载好的安装包。

4. 一路点击继续、安装。

5. 安装完成即可。


四、启动工具


【Windows 启动方法】

1. 打开工具文件夹。

2. 找到这个文件：
   start.bat

3. 双击 start.bat。

4. 第一次启动时，它会自动安装一些需要的小零件。
   这个过程可能会花几分钟。
   黑色窗口里会出现很多英文，不用害怕。

5. 等一会儿，浏览器会打开一个网页。

6. 如果浏览器没有自动打开，可以手动打开这个地址：
   http://localhost:8501


【macOS 启动方法】

1. 打开工具文件夹。

2. 找到这个文件：
   start.command

3. 双击 start.command。

4. 第一次启动时，它会自动安装一些需要的小零件。
   这个过程可能会花几分钟。
   终端窗口里会出现很多英文，不用害怕。

5. 等一会儿，浏览器会打开一个网页。

6. 如果浏览器没有自动打开，可以手动打开这个地址：
   http://localhost:8501


五、macOS 如果双击 start.command 没反应怎么办？

有时候 macOS 会说这个文件没有权限。

这时这样做：

1. 打开“终端”。

2. 输入：
   chmod +x 

   注意：x 后面有一个空格。

3. 把 start.command 这个文件拖进终端窗口。

4. 按回车。

5. 再回到文件夹，双击 start.command。


六、网页打开以后怎么用？

1. 选择记录来源。

   如果你手上有 txt 文件，就选“上传 txt 文件”。
   如果你只是复制了一段 log，就选“粘贴记录”。

2. 上传你要合并的多个 txt 文件，或者把 log 粘贴进文本框。

3. 如果需要，可以勾选几个输出选项：

   去除 QQ 号：不显示括号里的 QQ 号。
   去除时间：不显示日期和时间。
   去除括号开头内容：像“（好）”“（啊啊啊）”这种以括号开头的整条记录不输出。
   去除 [图片]：整条内容只有 [图片] 的记录不输出。
   按文件分段加小标题：不同来源切换时插入一个小标题。
   括号内容小一号 + 斜体：如果一整条发言的内容是从括号开始的，这整条发言都会变小并变成斜体，包括前面的人物名。
   括号内容单独染色：如果一整条发言的内容是从括号开始的，这整条发言都会使用单独的颜色，包括前面的人物名。

4. 每个文件旁边会出现一个底色选择器：

   底色：这一份 log 或粘贴来源在 Word 里的背景颜色。

5. 如果你勾选了“按文件分段加小标题”，还可以给每个文件/来源填写小标题。

   如果小标题留空，就会插入一个白色空行。

6. 人物名旁边会出现几个设置：

   显示名：可以把这个人物改成另一个名字。
   文字：这个人物在 Word 里的文字颜色。
   删除：勾选后，这个人物的全部发言都不会输出。

   如果什么都不选，默认就是白底黑字。

7. 选好颜色。

8. 在“输出文件名”那里填你想要的名字。
   比如：
   合并log.docx

9. 点击“生成 docx”。

10. 等它处理完成。

11. 点击“下载 docx”。


七、第一次启动为什么这么慢？

第一次启动时，工具会自动创建一个叫 .venv 的小环境。

你可以把它理解成：
工具给自己准备了一个小房间，把需要用到的零件都放进去。

这些零件包括：

streamlit
python-docx

第一次要下载和安装，所以慢。
之后再启动，一般就会快很多。


八、黑色窗口能不能关？

工具正在使用的时候，不要关黑色窗口。

黑色窗口就是工具的后台。
你关掉它，网页工具也会停掉。

等你生成并下载完 docx，不用了，再关掉黑色窗口。


九、我看到很多英文报错怎么办？

先不要慌。

最常见的问题有三个：

1. 没安装 Python。
2. Windows 安装 Python 时没有勾选 Add Python to PATH。
3. 第一次启动时网络不好，依赖没有下载成功。

可以先试试：

1. 关掉黑色窗口。
2. 重新双击 start.bat 或 start.command。
3. 等它重新安装。


十、这个工具会把我的 log 上传到网上吗？

不会。

这个工具是在你自己的电脑上运行的。
网页地址是：

http://localhost:8501

localhost 的意思是“这台电脑自己”。

所以你的 txt 和生成的 docx 都是在本机处理。


十一、怎么把这个工具给别人？

把这些文件发给对方：

app.py
requirements.txt
start.command
start.bat
README.md
老奶奶也能懂的启动说明.txt

不要把 .venv 文件夹发给别人。
.venv 是你这台电脑自己安装出来的环境，别人电脑上应该让它重新生成。


十二、最短使用口诀

装 Python。
打开工具文件夹。
Windows 双击 start.bat。
macOS 双击 start.command。
上传 txt。
选颜色。
生成 docx。
下载。
